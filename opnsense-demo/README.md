This project demonstrates how an OPNSense firewall can allow or block deviced from accessing a network a network based on their ip addresses. I used three virtual machines. OPNSense for the firewall, Ubuntu Server to run the scripts, and a Test client to check if everything worked. I made bash scripts that use the OPNSense api to add or remove ip addresses from an allow list. All three tests worked successfully, showing that the firewall is capable of controlling which devices are allowed to connect.
